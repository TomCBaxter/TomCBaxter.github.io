# TomCBaxter.github.io

Personal academic site of Thomas Baxter: https://tomcbaxter.github.io

A minimal Jekyll site: Markdown pages, one layout (`_layouts/default.html`) and one stylesheet (`style.css`). No theme, plugins, JavaScript or Gemfile. GitHub Pages builds it on every push.

- **Edit a page:** change the `.md` file (`index.md`, `notes.md`, `personal/…`) and push.
- **Add to the Cabinet of Curiosities:** put the image in `assets/img/gallery/` and add a block to `_data/gallery.yml`.
- **Preview locally:** `jekyll serve`, then open http://localhost:4000.

See [REDESIGN.md](REDESIGN.md) for how the site is put together, the colour rules and conventions.
